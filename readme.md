# ABI-Continuum

**An experimental fork of [ABI-Pipeline](https://github.com/neshani/ABI-Pipeline) by neshani.**

ABI-Continuum is intended to explore whole-book story analysis, persistent character and world-state tracking, and continuity-aware illustration generation for audiobooks.

**Current status:** Early development. The repository currently contains the original ABI-Pipeline code. ABI-Continuum's proposed features have not yet been released.

The original project's licensing terms are being clarified with its author. No independent ABI-Continuum release is currently available.
